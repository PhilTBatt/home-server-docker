# Lenovo ThinkCentre M720q Tiny

Facts are for the **Tiny (1L)** form factor. PSREF entry: "ThinkCentre M720 Tiny". The M720 SFF has a separate PSREF entry ([S3], seen in search results only) and is not covered here.

- **Form factor:** "Tiny (1L)" [S1][S2]
- **CPUs:** "Intel Celeron, Intel Pentium, 8th Generation Intel Core i3 / i5 / i7, or 9th Generation Intel Core i3 / i5 / i7 / i9 Processor" [S1]. Every CPU in the list has the T suffix: Celeron G4900T, G4930T; Pentium Gold G5400T, G5420T, G5500T, G5600T; Core i3-8100T, i3-8300T, i3-9100T, i3-9300T; i5-8400T, i5-8500T, i5-8600T, i5-9400T, i5-9500T, i5-9600T; i7-8700T, i7-9700T; i9-9900T [S1]
  - Socket: not stated [S1]. Intel lists the i5-8600T (one of the CPUs above) as socket FCLGA1151, TDP 35 W [S4]
  - Max TDP: not stated [S1]
- **Chipset:** "Intel B360 chipset" [S1]
- **Memory:** "Two DDR4 SO-DIMM slots, dual-channel capable"; "Up to 32GB DDR4-2666" [S1]
  - Footnote: "The max memory is based on the test results with current Lenovo memory offerings. The system may support more memory as the technology develops." [S1]
  - Speed depends on the CPU. The table lists DDR4-2400 for Celeron, Pentium and Core i3, and DDR4-2666 for Core i5, i7 and i9 [S1]
  - ECC: not stated [S1]. Intel lists ECC "No" for the i5-8600T [S4]
  - Max per stick: not stated [S1]
- **Built-in graphics:** Intel UHD Graphics 610 on Celeron G4900T/G4930T and Pentium G5400T/G5420T. Intel UHD Graphics 630 on Pentium G5500T/G5600T and all Core models [S1]. Every listed CPU has integrated graphics. The PSREF graphics section lists only integrated graphics [S2]
- **Expansion slots:** "One PCIe 3.0 x8, low-profile" and "Two M.2 slots (one for WLAN, one for SSD)" [S1]
  - Note: "2.5" HDD/SSD and PCIe card are mutually exclusive" [S1]
  - Card length, card power, riser and PCIe power cable: not stated [S1]
- **Storage:** "Up to two drives, 1x 2.5" HDD/SSD + 1x M.2 SSD"; "1x 2.5" disk bay" [S1]
  - M.2 SSD types listed: "M.2 2242 SSD PCIe NVMe, PCIe 3.0 x2" and "M.2 2280 SSD PCIe NVMe, PCIe 3.0 x4". Intel Optane Memory M10 is listed as PCIe 3.0 x2 [S1]
  - M.2 SATA SSD: none listed (not stated whether supported) [S1]
  - 2.5" types: SATA 6Gb/s SSD or HDD [S1]
  - RAID: not supported [S2]
  - SATA port count: not stated [S1]
- **Power supply:** external adapter, "65W Adapter 88% Autosensing", "90W Adapter 88% Autosensing", "135W Adapter 88% Autosensing", or "No power supply" [S1]. Connector type: not stated
- **Networking:** "Gigabit Ethernet, Intel Ethernet Connection I219-V, 1x RJ-45, supports Wake-on-LAN"; optional "Intel Ethernet Server Adapter I350-T4, 4x RJ-45, PCIe x4" [S1]
  - Wi-Fi is optional. The listed M.2 cards are Intel Wireless-AC 8265, Realtek RTL8821CE, Realtek RTL8822BE and Intel Wireless-AC 3165 (all Wi-Fi 5 + Bluetooth 4.2), or "No WLAN and Bluetooth" [S1]
  - The WLAN card uses one of the two M.2 slots. Key and size (e.g. 2230 key E): not stated [S1]
- **Upgrader trip-ups stated in the doc:**
  - The 2.5" drive and a PCIe card can't both be fitted [S1]
  - Celeron, Pentium and i3 CPUs run memory at DDR4-2400 [S1]
  - BIOS requirement for 9th-gen CPUs: not stated
