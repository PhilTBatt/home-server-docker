# Lenovo ThinkStation P330 SFF Gen 2

Facts are for the **P330 SFF Gen 2**.

- **Form factor:** "Mini-tower (8.4L)", 92.5 x 305.6 x 343.5 mm [S1]
- **CPUs:** socket "1x FCLGA1151" [S1]:
  - Pentium Gold G5620
  - Core i3-8100, 8300, 9100, 9300
  - Core i5-8500, 9400, **9400F**, 9500, 9600
  - Core i7-8700, 9700
  - Core i9-9900
  - Xeon E-2174G, **E-2224**, E-2224G, E-2226G, **E-2234**, **E-2236**, E-2244G, E-2246G, E-2274G, E-2276G, E-2278G
  - TDP: not stated [S1]
- **Chipset:** Intel C246 [S1]
- **Memory:** "4 DIMM sockets with 2 channels"; "Up to 64GB"; DDR4-2666 UDIMM ECC or non-ECC; "ECC on models with ECC DIMMs and Xeon processor" [S1]
  - Pentium and i3 rows list DDR4-2400 [S1]
- **Built-in graphics:** none on **i5-9400F, Xeon E-2224, E-2234, E-2236**. "DP needs Core, Pentium, or -G suffix Xeon processor" [S1]
- **Expansion slots** [S1]:
  - "Slot 1: PCIe 3.0 x16, low profile, links to CPU"
  - "Slot 2: PCIe 3.0 x1, low profile, links to PCH"
  - "Slot 3: PCIe 3.0 x16 (negotiable link width x4), low profile, links to PCH"
  - Card length: not stated
- **Graphics cards:** "Supports up to two NVIDIA Quadro P1000" [S1]
  - Listed: P400 30W, P620 40W, P1000 50W [S1]
  - Aux power connector: not stated (the column came back empty)
- **Storage:** "Up to 1x 3.5" SATA HDD / 2x 2.5" SATA HDD / SSD + 3x M.2 PCIe SSD" [S1]
  - Bays: slim ODD bay, 1x 3.5" (standard), 1x 2.5" (optional) [S1]
  - M.2: "1 via onboard slot" plus "2 via Single M.2 to PCIe adapter"; "M.2 PCIe SSD PCIe 3.0 NVMe" [S1]
  - RAID: SATA 0/1, PCIe 0/1 [S1]
  - SATA port count: not stated
- **Power supply:** 210W fixed (85%, Bronze) or 260W fixed (92%, Platinum) [S1]
- **Networking:** Intel I219-LM GbE with Wake-on-LAN. "Additional Ethernet options via PCIe adapter" [S1]
  - Wi-Fi is optional: Intel AC 9560 "M.2 card" [S1]
