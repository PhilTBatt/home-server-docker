# Decision records

One file per significant decision about this repo (the services, the API and the phone page), numbered in order: `0001-short-title.md`.
Each says what problem needed a decision, the options considered, what was chosen and why, how confident the choice was, and the strongest case against it.

## When to write one
- The decision would be costly to reverse, or someone will later ask "why is it like this?"
- Not for small choices that are easy to change.

## Rules
- Copy `template.md`, give it the next number, and set its Status.
- Once accepted, a record isn't edited apart from its Status line. A change of mind is a new record, and the old one becomes "replaced by NNNN".
- Started 2026-11-13. Earlier decisions aren't back-filled.
- Nothing personal or secret: this repo is public.
