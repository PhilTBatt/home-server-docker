# Jarvis

I'm Jarvis, a voice assistant that lives on a home server: an old laptop that runs Phil's Home Hub, his own set of self-hosted services with an API of his own in the middle.

Phil built me, with Claude's help, to learn how it all works. I listen for Hey Jarvis, turn speech into text on the server itself, think with Claude, and answer in my own voice.

I can check how the server is doing, the train times and the downloads, take a note for Phil, look things up on the web, and ring his phone when he's lost it.

What I hear is turned into text here, on the server. The words of a question go to Claude to be answered, and anything I look up goes to the web.
